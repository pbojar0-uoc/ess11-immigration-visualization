# Actitudes hacia la Inmigración en Europa: España vs Polonia

**Autor:** Patryk Bojar  
**Asignatura:** Visualización de Datos (UOC) - Práctica 2  
**Fuente:** European Social Survey Round 11 (2023-2024)  
**DOI:** [10.21338/ess11e04_1](https://doi.org/10.21338/ess11e04_1)

---

## 📋 Descripción del Proyecto

Como ciudadano polaco residente en España, este proyecto explora las diferencias en actitudes hacia la inmigración entre ambos países y el resto de Europa, respondiendo a 4 preguntas clave:

1. ¿Existen diferencias significativas entre España y Polonia?
2. ¿Las personas de derecha tienen actitudes más negativas?
3. ¿Los jóvenes son más abiertos que las generaciones mayores?
4. ¿Hay relación entre educación y apertura hacia la diversidad?
